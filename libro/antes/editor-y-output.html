📝 La hoja de scripts y la ventana Output

Cuando hacés doble clic en un script de la lista, se abre una hoja para escribir código. Y abajo está la ventana Output (quiere decir salida): ahí el juego te habla.

1. La hoja de scripts

  • Cada renglón tiene un número de línea a la izquierda. Sirve para encontrar los errores.
  • El código se pinta de colores solo. Cada color es un tipo de palabra. Mirá los colores del código.
  • Mientras escribís, Studio te sugiere palabras. Apretá Tab o Enter para aceptar.
  • Si algo está mal escrito, aparece una rayita roja abajo, como en un dictado. 〰️

2. La ventana Output

Se abre en View → Output. Muestra tres tipos de mensajes:

ColorQué es¿Qué hago?
⬛ Negro o blancoUn print(...) nuestro.Nada, ¡el script anda!
🟨 AmarilloUn aviso. Algo raro, pero no se rompió.Leerlo con el tío.
🟥 RojoUn error. El script se frenó ahí.Hacer clic: te lleva a la línea.

El error dice dónde está: Reglas:3 = script Reglas, línea 3.

El ciclo de arreglar un error 🔁

💡 Equivocarse es normal. ¡Los programadores grandes ven errores rojos todos los días! Lo importante es leer qué dice.
💡 Truco: poné print("llegué acá") en el medio del código. Si no aparece en Output, el script no llegó hasta esa línea.
