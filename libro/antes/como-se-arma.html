🧭 El camino para armar cualquier cosa

Una escalera, una zona segura, un gusano… ¡Todo se arma con el mismo camino! Seguí las flechas. 👇

👆 Cada cajita te lleva a la parte de Roblox Studio que usás en ese paso.

Qué parte de Studio usás en cada paso

PasoParte de Roblox StudioTenés que saber…

Ejemplo: así armamos una zona segura 🛡️

  1. Pensar: "Un piso verde al lado de la escalera. Si estás arriba, el gusano no te toca."
  2. Crear: Home → Part.
  3. Cómo es: Size 10, 1, 10, Color verde, Material DiamondPlate, Anchored ☑. (Después le sumamos el Escudo.)
  4. Dónde va: con Move, al lado del escalón 10.
  5. Ordenar: Rename → Piso. Lo junto con el Escudo (Ctrl + G), llamo al grupo ZonaSegura1 y lo arrastro a TorreEspacio → ZonasSeguras.
  6. ¿Hace algo? ¡Sí! El script Partida se fija si estás arriba. No hizo falta un script nuevo: ya existía.
  7. Probar: Play, me paro arriba, viene el gusano… ¡no me toca! Stop. Save to Roblox. 💾
