🍌 Script Objetos: juguetes flotando y bananas

🎮¿Dónde se ve en el juego?
Volver a juguetes, bate y bananas.
📍 Dónde está: ServerScriptService → Objetos (un Script). Pone las cosas en la carpeta TorreEspacio → Objetos cuando empieza el juego.

Números que podés cambiar 🎚️

local VUELVE_A_APARECER = 20   -- segundos hasta que aparece otro juguete
local MAXIMO_EN_LA_MANO = 3    -- cuántos juguetes podés llevar
local RESBALA = 3              -- cuántos escalones para atrás te manda la banana

Repartir parejo

-- Una pelota por cada vuelta de la torre (12 escalones)
for vuelta = 1, N / 12 do
    juguete({"PelotaFutbol", "PelotaTenis", "PelotaRugby"}, (vuelta - 1) * 12 + 2, vuelta * 12 - 1)
end
-- Pocos bates: uno cada 32 escalones
for parte = 1, 3 do
    juguete({"BateJuguete"}, (parte - 1) * 32 + 4, parte * 32 - 2)
end
-- Una banana cada 8 escalones
for i = 1, N / 8 do
    banana(math.max(5, (i - 1) * 8 + 1), i * 8)
end

La torre se divide en pedazos iguales y en cada pedazo va una cosa, en un escalón al azar (math.random(desde, hasta)). Así nunca quedan todas juntas.

Agarrar un juguete

muestra.Touched:Connect(function(golpe)
    local jugador = jugadorDe(golpe)
    if not jugador or muestra.Transparency > 0 then return end
    if cuantosJuguetes(jugador) >= MAXIMO_EN_LA_MANO then return end
    juguetes[nombre]:Clone().Parent = jugador.Backpack   -- ¡a tu mochila!
    muestra.Transparency = 1                             -- desaparece
    task.delay(VUELVE_A_APARECER, function()
        ...                                              -- y vuelve en otro escalón
    end)
end)
  • jugador.Backpack = la mochila del jugador. Lo que pongas ahí aparece abajo en la pantalla.
  • task.delay(20, …) = "dentro de 20 segundos, hacé esto".

Resbalar con la banana 🍌

local function resbalar(jugador, k)
    local atras = math.max(1, k - RESBALA)          -- 3 escalones para atrás
    humanoide.PlatformStand = true                  -- se cae de cola
    personaje:PivotTo(CFrame.new(arribaDe(atras, 3.5)) * CFrame.Angles(math.rad(-80), 0, 0))
    Partida.mensaje(jugador, "🍌 ¡Resbalaste!\nVolviste " .. RESBALA .. " escalones")
    task.delay(0.8, function()
        humanoide.PlatformStand = false             -- se levanta
    end)
end
  • PlatformStand = true = el personaje queda tirado, sin poder caminar.
  • CFrame.Angles(math.rad(-80), 0, 0) = lo acuesta para atrás. ¡Pum! 🤕
  • math.max(1, …): si estás en el escalón 2, no podés ir al −1. Vas al 1. ¡Nunca te caés del mapa!
⭐⭐ Desafío: ¿Hiciste la pelota de básquet? Agregá "PelotaBasquet" a la lista {"PelotaFutbol", "PelotaTenis", "PelotaRugby"} para que aparezca en la torre.
