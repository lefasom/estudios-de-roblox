💻 ¿Qué es un script?

Un script es una lista de órdenes para el juego, escrita en un idioma que se llama Luau. Es como una receta: el juego la lee de arriba para abajo y hace lo que dice.

¡Casi todos los scripts de un juego son así! Cuando pasa algo → si se cumple algo → hacé algo.

Cómo crear un script (a mano)

  1. En la lista, pasá el mouse por arriba del lugar donde lo querés (por ejemplo ServerScriptService).
  2. Apretá el + que aparece al lado.
  3. Elegí Script (o LocalScript).
  4. Se abre una hoja para escribir. Ya trae print("Hello world!"): borralo.
  5. Cambiale el nombre (clic derecho → Rename) para saber qué hace.
  6. Escribí el código y apretá ▶ Play para probarlo.
💡 Si algo no anda, mirá la ventana Output (View → Output). Ahí aparecen los errores en rojo, con el número de línea.
