🎮¿Dónde se ve en el juego?
Los bloques trampa y el dado.

Está en ServerScriptService → Trampas. Es un Script (corre en el servidor), así todos los jugadores ven las mismas trampas.

Los números que podés cambiar 🎚️

local TRAMPAS_AL_EMPEZAR = 8      -- trampas con dificultad 0
local TRAMPAS_POR_NIVEL = 3       -- trampas de más por cada punto de dificultad
local DADOS_AL_EMPEZAR = 3        -- dados con dificultad 0
local QUEDA_MIN, QUEDA_MAX = 25, 45   -- segundos en un escalón antes de mudarse
local PROB_ATRAS = 2 / 3          -- el 66% de las veces el dado te manda para ATRÁS

📈 La dificultad

Cada 2 segundos el script mira cuántas Vueltas ganó cada jugador del servidor. El que tiene más manda. Ese número (de 0 a 5) es la dificultad.

La dificultad se guarda como atributo en TorreEspacio. El script Gusanos lo lee así:

local d = torre:GetAttribute("Dificultad") or 0
local maximo = MAXIMO_EXTRA + d

Además, más arriba en la torre = más difícil: hay más trampas cerca de la cima, y ahí se rompen y giran más rápido.

🧊 Se rompe

if #pisando(e) > 0 then
	-- tiembla y se pone transparente... ¡crack!
	e.CanCollide = false; e.Transparency = 1
	-- se vuelve a armar cuando ya nadie está encima
	while #pisando(e, 9) > 0 do task.wait(0.3) end
	e.CanCollide = true
end

⬇️ Se cae

Cuando lo pisás, titila amarillo y rojo unos segundos. Después se va 30 para abajo, espera y vuelve a subir despacito.

↕️ Elevador

Arma un patrón de 3 partes. Cada parte tiene un tiempo de subir y otro de bajar, elegidos al azar. Después repite el mismo patrón. ¡Miralo antes de saltar!

for _ = 1, 3 do
	table.insert(patron, azar(0.5, 2.5))   -- cuánto tarda en subir
	table.insert(patron, azar(0.5, 2.5))   -- cuánto tarda en bajar
end

🔄 Jenga

El escalón se vuelve una tabla larga y finita. Cada 1 a 3 segundos gira 90° (un cuarto de vuelta) sobre su centro.

🎲 El dado y su hitbox exacta

Cada cuadrito, el script le pregunta a Roblox: "¿qué partes están ADENTRO del cubo del dado?". Para eso usa GetPartsInPart (en inglés: "partes adentro de la parte").

for _, parte in ipairs(workspace:GetPartsInPart(d.parte, filtro)) do
	local jugador = Players:GetPlayerFromCharacter(parte.Parent)
	if jugador then
		task.spawn(tirarDado, d, jugador)
	end
end
💡 Antes (con la banana y el agujero negro) había una caja invisible más grande que el dibujo. Por eso te agarraba aunque no lo tocaras. Ahora se usa el cubo mismo.
local atras = math.random() < PROB_ATRAS   -- 2 de cada 3 veces: true

math.random() da un número entre 0 y 1. Es menor que 0.66 dos de cada tres veces.
