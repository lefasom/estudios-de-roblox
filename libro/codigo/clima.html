🌦️ Scripts Clima, ClimaLocal y PoseParaguas

🧭 Antes de esto tenés que conocer: La lista, ¿Qué es un script? y Flotar y Paraguas.

Ya no hay menú de clima. Ahora el juego elige el clima al azar. Cuanto más difícil está el juego, más feo es el clima. Trabajan 3 scripts juntos:

1. Clima (Script del servidor) 🎲

Está en ServerScriptService → Clima. Cada 90 a 150 segundos tira un dado con pesos: los climas con más peso salen más seguido.

Despejado = math.max(5, 40 - 7 * d),   -- ☀️ cada vez menos
Lluvia = 25,
Nieve = 15 + 2 * d,
Viento = 10 + 3 * d,
Tormenta = 5 * d,                      -- ⛈️ solo si ya ganaron alguna vuelta

d es la dificultad. Con d = 0 la tormenta tiene peso 0: ¡nunca sale!

2. ClimaLocal (LocalScript) 🌧️

Está en StarterPlayer → StarterPlayerScripts → ClimaLocal. Hace 5 cosas en cada cuadrito:

  1. La luz ☁️: más oscuro con lluvia, muy oscuro con tormenta, y ⚡ relámpagos.
  2. Lo que cae: una nube invisible arriba de la cámara tira gotas, copos o rayitas de viento (son ParticleEmitter).
  3. Ráfagas 💨: cada tanto el viento sopla fuerte para atrás en la escalera y te retrasa.
  4. Resbalar ❄️: con nieve, si te quedás quieto te vas resbalando de a poquito para afuera.
  5. El piso: arriba de cada escalón pone una capa finita. Con lluvia es brillante, como agua 💧. Con nieve es blanca y se junta despacito ❄️.

¿Cuánto clima hay? Depende de qué tan arriba estás:

local function cuanto(y)
	local d = torre:GetAttribute("Dificultad") or 0
	local a = math.clamp((y - ABAJO) / (ARRIBA - ABAJO), 0, 1)   -- 0 abajo, 1 en la meta
	local desde = math.max(0.05, 0.55 - 0.1 * d)                 -- con más dificultad, empieza más abajo
	local fuerte = math.clamp((a - desde) / (1 - desde), 0, 1)
	return 0.4 + 0.6 * fuerte, fuerte
end
💡 math.clamp(x, 0, 1) quiere decir "dejá x entre 0 y 1". Si da −3, queda 0. Si da 5, queda 1.
🛡️ En las zonas seguras el viento y la nieve no te mueven.
if soplando then
	raiz.CFrame += atras * fuerza * f * EMPUJE_PISO * dt   -- te retrasa
end

El paraguas también sufre el viento: en Flotar, VIENTO_PARAGUAS = 0.3.

3. PoseParaguas (LocalScript) ☂️🤸

Cuando tenés el paraguas abierto, la mano derecha lo sostiene arriba y la izquierda hace equilibrio. Se mueve para el lado contrario al que vas, ¡como cuando caminás por un cordón!

No es una animación guardada. El script gira las articulaciones (hombros, codos, cintura, piernas) en cada cuadrito. Usa un resorte: el brazo se pasa un poquito y vuelve, así parece de verdad.

local costado = resorte(s, "costado", math.clamp(v.X * BALANCEO + giro * 6, -40, 40), dt)
poner(s.j.hombroIzq, grados(adelante * 0.8, 0, -80 - costado + ondita * 8))
💡 Tu compu hace la pose de todos los que tienen el paraguas. Así ves a tus amigos haciendo equilibrio.
