📥 Funciones 2: le das cosas y te devuelve cosas

Algunas máquinas necesitan ingredientes. Una licuadora 🥤: le das frutas y te devuelve un licuado.

  • Lo que entra se llama parámetro. Va adentro de los paréntesis ( ).
  • Lo que sale se devuelve con la palabra return (quiere decir devolver).

Paso 1: solo lo que entra (parámetros)

Esta máquina saluda a quien le digas:

local function saludar(nombre)
    print("¡Hola, " .. nombre .. "!")
end

saludar("Dylan")     -- sale: ¡Hola, Dylan!
saludar("tío")       -- sale: ¡Hola, tío!
  • nombre es una cajita vacía 📦. Cada vez que usás la máquina, le ponés algo adentro.
  • La primera vez, nombre = "Dylan". La segunda, nombre = "tío".
  • .. (dos puntitos) pega textos: "¡Hola, " .. "Dylan" = "¡Hola, Dylan".

Paso 2: muchas cosas que entran

Separadas con comas. Entran en el mismo orden en que las escribís:

local function marear(gusano, segundos)
    print(gusano .. " queda mareado " .. segundos .. " segundos 😵")
end

marear("GusanoLoco", 3)     -- pelota: 3 segundos
marear("GusanoLargo", 5)    -- bate: 5 segundos

Paso 3: lo que sale (return)

Con return la máquina te devuelve una respuesta. Vos la guardás en una variable:

local function doble(numero)
    return numero * 2
end

local resultado = doble(5)
print(resultado)            -- sale: 10
  1. Entra el 5. Adentro, numero = 5.
  2. Hace la cuenta: 5 × 2 = 10.
  3. return devuelve el 10.
  4. El 10 cae en la cajita resultado. 📦
💡 Cuando la máquina llega a return, termina. Lo que está abajo del return no se hace.

¡Una función de verdad de mi juego! 🏆

Así calcula Partida tus puntos cuando llegás arriba. Entran los segundos que tardaste y las piezas de armadura que tenés. Sale cuántos puntos te ganaste:

local function calcularPuntos(segundos, piezas)
    local base = math.max(100, 5000 - 15 * segundos)
    return base * (1 + 0.1 * piezas)
end

print(calcularPuntos(120, 0))   -- 2 minutos, sin armadura: 3200
print(calcularPuntos(120, 3))   -- 2 minutos, 3 piezas: 4160

En el script de verdad está mezclada con otras cosas, pero hace esta misma cuenta.

⭐ Desafío 2: usá la máquina calcularPuntos. ¿Cuántos puntos da si tardás 60 segundos y tenés 7 piezas?
👀 Ver la respuesta

5000 − 15 × 60 = 5000 − 900 = 4100. Con 7 piezas: 4100 × 1.7 = 6970 puntos. ¡Un campeón! 🏆

⭐ Desafío 3: armá una función sumar(a, b) que devuelva a + b. Probala con print(sumar(3, 4)).
👀 Ver la respuesta 
local function sumar(a, b)
    return a + b
end

print(sumar(3, 4))   -- sale: 7
