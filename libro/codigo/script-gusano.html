🎮¿Dónde se ve en el juego?
Volver a los 5 gusanos.
📍 Dónde está: ServerScriptService → Gusanos. Es un Script (del servidor): así los gusanos son los mismos para todos los jugadores. Si vos ves al gusano en el escalón 20, tu amigo también lo ve ahí. ¡No hay cuenta regresiva para nadie!

Los scripts de la torre trabajan en equipo

Cuando un gusano te toca, el script Gusanos no decide qué pasa: le avisa a Partida con Partida.atrapar(jugador). Partida se fija si tenés armadura. ¡Cada script hace su trabajo! 👷

local Partida = require(script.Parent:WaitForChild("Partida"))

require = "traeme las funciones de ese otro script". Partida es un ModuleScript: un script que presta sus funciones a otros.

local TIPOS = {"GusanoLoco", "GusanoForzudo", "GusanoLargo", "GusanoCortito"}

Parte 2: el camino

local puntos = {}
for k = 1, #escalones:GetChildren() do
    puntos[k] = escalones:WaitForChild("Escalon" .. k).Position + Vector3.new(0, 2.5, 0)
end

local function camino(t)
    local k = math.floor(t)
    return puntos[k]:Lerp(puntos[k + 1], t - k)   -- un punto entre dos escalones
end

Cada gusano tiene un número t = por qué escalón va. Si t = 10.5, está entre el 10 y el 11. Lerp = "un punto en el medio del camino".

Parte 3: sacar un gusano del molde

local function nuevoGusano(nombre, t, hoyo)
    local modelo = moldes[nombre]:Clone()      -- copia del molde de ServerStorage
    local g = {
        modelo = modelo, t = t, desde = t, hoyo = hoyo,
        velocidad = modelo:GetAttribute("Velocidad"),
        forma = modelo:GetAttribute("Forma"),
        grande = (nombre == "GusanoGrande"),
    }
    modelo.Parent = activos                    -- ¡aparece en la torre!
    if hoyo then hoyo.Humo:Emit(30) end        -- ¡puf! humo del hoyo
    table.insert(lista, g)
end
  • :Clone() = "hacé una copia". El molde queda guardado para la próxima.
  • GetAttribute("Velocidad") lee el atributo que le pusimos al gusano. Así cada gusano tiene su velocidad sin cambiar el código.
  • Las bolitas que todavía no salieron se quedan adentro del hoyo: parece que el gusano va saliendo de a poco.

Parte 5: el forzudo salta y golpea 💪

local function saltar(g, dt, mareado)
    if not mareado then g.reloj += dt end
    if g.reloj >= VUELO + PAUSA then      -- terminó un salto: el próximo
        g.reloj = 0
        g.escalon += 2                    -- ¡de a 2 escalones!
        g.golpeo = false
    end
    local a = math.min(g.reloj / VUELO, 1)          -- 0 = arranca, 1 = cae
    local p0, p1 = sobre(g.escalon), sobre(g.escalon + 2)
    local lugar = p0:Lerp(p1, a) + Vector3.new(0, math.sin(a * math.pi) * 10, 0)
    ...
    if a >= 1 and not g.golpeo and not mareado then
        g.golpeo = true
        golpe(p1)                         -- ¡PUM! solo cuando cae
    end
end
  • math.sin(a * math.pi) * 10 hace la curva del salto: sube hasta 10 en el medio y baja. 🌈
  • Solo golpea cuando cae, en el escalón donde cae. Si estás en el escalón que salta por arriba, ¡te salvaste!
  • El golpe hace una onda roja que se agranda (con TweenService, que cambia algo de a poquito).

Parte 6: cada cuadrito 💓

RunService.Heartbeat:Connect(function(dt)
    for i = #lista, 1, -1 do
        local g = lista[i]
        local mareado = ahora() < (g.modelo:GetAttribute("MareadoHasta") or 0)
        g.cabeza.Mareo.Enabled = mareado            -- cartel "💫 ¡Mareado!"

        if g.forma == "salta" then
            saltar(g, dt, mareado)
        else
            if not mareado then g.t += g.velocidad * dt end   -- siempre igual
            dibujar(g, mareado)
            if not mareado then tocar(g) end                   -- ¿tocó a alguien?
        end

        if g.grande and g.t > N + 6 then
            g.t = DORMIDO            -- el grande vuelve a empezar: ¡nunca se va!
        elseif not g.grande and (g.t > g.desde + RECORRIDO or g.t > N) then
            sacar(g)                 -- los de los hoyos se esconden
        end
    end
end)
  • Heartbeat = el "latido" del juego, unas 60 veces por segundo.
  • Si el gusano está mareado (le pegaste con un juguete), no avanza y no toca a nadie. ¡Pasá rápido! 🏃
  • tocar(g) mide la distancia (.Magnitude) entre vos y cada bolita. Si estás muy cerca → Partida.atrapar(jugador).

Parte 7: el hoyo avisa — 3, 2, 1 🔢

local function sacarDeUnHoyo()
    local hoyo = elegirHoyo()
    if not hoyo then return end        -- todos los hoyos están ocupados
    ocupado[hoyo] = true
    task.spawn(function()
        hoyo.Contador.Enabled = true
        for n = CUENTA, 1, -1 do       -- 3, 2, 1
            hoyo.Contador.Numero.Text = tostring(n)
            if n == 1 then pintarHoyo(hoyo, ROJO) else pintarHoyo(hoyo, AMARILLO) end
            task.wait(1)
        end
        hoyo.Contador.Enabled = false  -- ¡pum! se va el número…
        local tipo = TIPOS[math.random(1, #TIPOS)]
        nuevoGusano(tipo, hoyo:GetAttribute("Escalon"), hoyo)   -- …y sale el gusano
    end)
end
  • for n = CUENTA, 1, -1 = "contá desde 3 hasta 1, para atrás" (el -1 es de a uno para abajo).
  • task.spawn = "hacé esto aparte". Así, mientras el hoyo cuenta, ¡los otros gusanos se siguen moviendo!
  • pintarHoyo(hoyo, color) es una función nuestra: pinta el borde, la luz y el número del mismo color.
  • ocupado[hoyo]: mientras un hoyo cuenta o un gusano sale, no se puede elegir para otro.

¿Cuándo vuelve a amarillo? En cada latido, el script se fija si el gusano ya salió entero:

local function yaSalio(g)
    if g.forma == "salta" then
        return g.escalon > g.desde                         -- ya dio su primer salto
    end
    return g.t - #g.partes * g.separacion >= g.desde    -- la cola ya está afuera
end

Mientras no salió entero, g.saliendo es true y si te toca… ¡te empuja! 💨 Cuando sale entero, el hoyo vuelve a amarillo y ahí sí te atrapa.

Y el Forzudo, cuando cae, llama a Partida.atrapar(jugador, PIEZAS_FORZUDO): ¡te saca 2 piezas! 💪 (ver Partida)
