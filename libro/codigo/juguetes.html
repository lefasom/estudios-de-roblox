Volver a los juguetes y el bate.

¿Dónde está cada cosa? (el enlace)

Cada juguete (Tool) tiene adentro un Script chiquito llamado AlHacerClic. Ese script no sabe lanzar: le pide ayuda al ModuleScript Juguetes con require. Así, si mejorás cómo se lanza, ¡mejoran todas las pelotas juntas!

El script de la pelota (AlHacerClic)

-- Cuando hacés clic, la pelota sale volando. Si le pega a un gusano, lo marea.
local Juguetes = require(game:GetService("ServerScriptService"):WaitForChild("Juguetes"))
local herramienta = script.Parent

herramienta.Activated:Connect(function()
    Juguetes.lanzar(herramienta, {mareo = 3, gastar = true})
end)
  • Activated = "cuando hacés clic con la herramienta en la mano".
  • {mareo = 3, gastar = true} = las opciones: marea 3 segundos y la pelota se gasta.

El del bate es igual, pero dice Juguetes.batear(herramienta, {mareo = 5, alcance = 11}).

Lanzar: la pelota vuela con gravedad 🌍

local inicio = mano.Position
local velocidad = raiz.CFrame.LookVector * 90 + Vector3.new(0, 18, 0)
local gravedad = Vector3.new(0, -60, 0)

conexion = RunService.Heartbeat:Connect(function(dt)
    t += dt
    local lugar = inicio + velocidad * t + gravedad * (t * t / 2)
    pelota.CFrame = CFrame.new(lugar)
    local gusano = gusanoEn(lugar, pelota.Size.X / 2 + 0.5)
    if gusano or t > 1.6 then
        conexion:Disconnect()           -- dejar de mover la pelota
        pelota:Destroy()
        if gusano then Juguetes.aturdir(gusano, opciones.mareo) end
    end
end)
  • LookVector = "para dónde mirás". La pelota sale para adelante (90) y un poquito para arriba (18).
  • La gravedad la va tirando para abajo: por eso hace una curva, como una pelota de verdad. 🌈
  • En cada cuadrito se fija si la pelota está tocando algún gusano (gusanoEn).
💡 Usá el Shift Lock para apuntar: con Shift Lock, tu personaje mira para donde mira la cámara. 🎯

Batear: hay que estar ADELANTE y CERCA

local mira = raiz.CFrame.LookVector
for _, gusano in ipairs(activos:GetChildren()) do
    for _, p in ipairs(gusano:GetDescendants()) do
        if p:IsA("BasePart") then
            local hacia = p.Position - raiz.Position
            local adelante = hacia.Unit:Dot(mira) > 0.3      -- ¿está adelante mío?
            if adelante and hacia.Magnitude < opciones.alcance + p.Size.X / 2 then
                Juguetes.aturdir(gusano, opciones.mareo)
                break
            end
        end
    end
end
  • :Dot mide si dos flechas apuntan para el mismo lado. Si da más de 0.3, el gusano está adelante. Si está atrás tuyo… ¡no le pegás! Por eso tenés que darte vuelta para pegarle.
  • Después el bate gira (cambiando el Grip, el agarre) para que se vea el golpe. 🏏

Marear al gusano

function Juguetes.aturdir(gusano, segundos)
    local hasta = workspace:GetServerTimeNow() + segundos
    gusano:SetAttribute("MareadoHasta", hasta)
end

Le escribe al gusano un atributo: "estás mareado hasta tal hora". El script Gusanos lo lee y lo frena. ¡Los scripts se dejan mensajes con atributos! 📝
