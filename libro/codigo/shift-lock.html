🔒 Script del Shift Lock

🧭 Antes de esto tenés que conocer: Funciones 1 y Funciones 3 (eventos).

Con Shift Lock la cámara queda fija atrás de tu personaje y el mouse en el centro. Así es más fácil saltar derecho en la torre.

  • Apretás Shift → se prende 🔒. Apretás otra vez → se apaga 🔓.
  • Abajo a la derecha hay un botón que dice si está prendido o no (y sirve en celular).
📍 Dónde está: StarterPlayer → StarterPlayerScripts → ShiftLock. Es un LocalScript, porque maneja tu cámara y tus teclas.

Roblox ya trae un Shift Lock, pero cada jugador tiene que prenderlo en su menú. Por eso hicimos uno propio que siempre funciona. Para que no haya dos peleándose, apagamos el de Roblox: elegí StarterPlayer → característica EnableMouseLockOption → ☐ destildado.

Parte 1: los servicios

local Players = game:GetService("Players")
local UserInputService = game:GetService("UserInputService") -- teclas y mouse
local RunService = game:GetService("RunService")             -- el reloj del juego

local jugador = Players.LocalPlayer   -- VOS (solo existe en un LocalScript)
local camara = workspace.CurrentCamera
local prendido = false                -- empieza apagado

Parte 2: el botón en la pantalla

local gui = Instance.new("ScreenGui")      -- una "hoja" pegada a tu pantalla
gui.Name = "ShiftLockGui"
gui.ResetOnSpawn = false
gui.Parent = jugador:WaitForChild("PlayerGui")

local boton = Instance.new("TextButton")   -- un botón con letras
boton.Size = UDim2.fromOffset(150, 44)
boton.AnchorPoint = Vector2.new(1, 1)
boton.Position = UDim2.new(1, -20, 1, -20) -- abajo a la derecha
boton.Font = Enum.Font.FredokaOne
boton.TextSize = 20
boton.TextColor3 = Color3.new(1, 1, 1)
boton.Parent = gui
Instance.new("UICorner", boton).CornerRadius = UDim.new(0, 10) -- esquinas redondas

Instance.new = "crear una cosa nueva" desde el código. Es lo mismo que apretar + en la lista, pero con código.

Parte 3: prender y apagar

local function pintar()
    if prendido then
        boton.Text = "🔒 Shift Lock: SÍ"
        boton.BackgroundColor3 = Color3.fromRGB(0, 170, 90)   -- verde
    else
        boton.Text = "🔓 Shift Lock: NO"
        boton.BackgroundColor3 = Color3.fromRGB(60, 60, 60)   -- gris
    end
end

local function cambiar()
    prendido = not prendido   -- si estaba prendido, se apaga; y al revés
    pintar()
    local personaje = jugador.Character
    local humanoide = personaje and personaje:FindFirstChildOfClass("Humanoid")
    if humanoide then
        humanoide.AutoRotate = not prendido
        humanoide.CameraOffset = prendido and Vector3.new(1.75, 0, 0) or Vector3.zero
    end
    if not prendido then
        UserInputService.MouseBehavior = Enum.MouseBehavior.Default
    end
end
  • not = "lo contrario". not true es false.
  • AutoRotate = el personaje gira solo para donde camina. Con Shift Lock lo apagamos, porque gira para donde mira la cámara.
  • CameraOffset = corre la cámara un poquito a la derecha (1.75), para ver por arriba del hombro.

Parte 4: escuchar la tecla y el botón

boton.MouseButton1Click:Connect(cambiar)   -- CUANDO hacés clic en el botón

UserInputService.InputBegan:Connect(function(input, ocupado)
    if ocupado then return end -- por ejemplo, si está escribiendo en el chat
    if input.KeyCode == Enum.KeyCode.LeftShift or input.KeyCode == Enum.KeyCode.RightShift then
        cambiar()
    end
end)

InputBegan = "cuando aprietan una tecla". Si es Shift (el de la izquierda o el de la derecha), prende o apaga.

Parte 5: cuando reaparecés

jugador.CharacterAdded:Connect(function(personaje)
    local humanoide = personaje:WaitForChild("Humanoid")
    humanoide.AutoRotate = not prendido
    humanoide.CameraOffset = prendido and Vector3.new(1.75, 0, 0) or Vector3.zero
end)

Parte 6: en cada cuadrito de la pantalla

RunService:BindToRenderStep("ShiftLock", Enum.RenderPriority.Camera.Value + 1, function()
    if not prendido then return end
    UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter -- mouse al centro
    local personaje = jugador.Character
    local raiz = personaje and personaje:FindFirstChild("HumanoidRootPart")
    if raiz then
        local mira = camara.CFrame.LookVector          -- para dónde mira la cámara
        local plano = Vector3.new(mira.X, 0, mira.Z)   -- sin mirar arriba ni abajo
        if plano.Magnitude > 0.01 then
            raiz.CFrame = CFrame.lookAt(raiz.Position, raiz.Position + plano)
        end
    end
end)

pintar()

El juego dibuja la pantalla unas 60 veces por segundo. BindToRenderStep = "cada vez que dibujás, hacé esto". Así el personaje siempre mira para donde mira la cámara.

🎯 Jueguito: ¿cómo hago que el botón diga "ON" y "OFF"?

En pintar(), cambiá "🔒 Shift Lock: SÍ" por "ON" y "🔓 Shift Lock: NO" por "OFF".

🎯 Jueguito: quiero que se prenda con la tecla Ctrl en vez de Shift.

Cambiá LeftShift por LeftControl y RightShift por RightControl.
