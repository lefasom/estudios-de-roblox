🌙 Script de la noche: CieloEspacio

🎮¿Dónde se ve en el juego?
Volver a las estrellas y planetas.

Cuando llegás cerca de la torre, el cielo se pone de noche y se ven las estrellas ✨. Cuando te vas, vuelve a ser de día ☀️.

📍 Dónde está: StarterPlayer → StarterPlayerScripts → CieloEspacio. Es un LocalScript: así se hace de noche solo para vos, y no para un amigo que está en otro lado.
-- Cielo del espacio: cuando estás cerca de la Torre del Espacio, se hace de noche (solo para vos).
local Players = game:GetService("Players")
local Lighting = game:GetService("Lighting")   -- la luz del juego (sol, hora)

local jugador = Players.LocalPlayer
local CENTRO = Vector3.new(6000, 0, 6000)      -- dónde está la torre
local horaNormal = Lighting.ClockTime          -- la hora de siempre

while true do
    local raiz = jugador.Character and jugador.Character:FindFirstChild("HumanoidRootPart")
    if raiz then
        local lejos = (Vector3.new(raiz.Position.X, 0, raiz.Position.Z) - CENTRO).Magnitude
        if lejos < 700 then
            Lighting.ClockTime = 0      -- medianoche: se ven las estrellas
        else
            Lighting.ClockTime = horaNormal
        end
    end
    task.wait(0.5)
end
  • ClockTime = la hora del juego. 0 = medianoche 🌙, 12 = mediodía ☀️.
  • while true do … end = "repetí esto para siempre".
  • task.wait(0.5) = "esperá medio segundo" antes de volver a fijarte. ¡Siempre hay que esperar adentro de un while true, si no la compu se cuelga! 🥶
  • .Magnitude = la distancia. Si estás a menos de 700 de la torre, es de noche.

Probalo a mano (sin script)

  1. En la lista, elegí Lighting.
  2. En las características, cambiá ClockTime a 0. ¡Se hace de noche en Studio!
  3. Volvé a ponerlo como estaba (14.5).
