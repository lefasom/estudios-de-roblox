🌈 Los colores del código

En este libro el código está pintado de colores. Cada color es un tipo de palabra. ¡Así se lee mucho más fácil!

(La hoja de scripts de Roblox Studio también pinta el código. Sus colores pueden ser un poco distintos, pero la idea es la misma.)

ColorQué esEjemplos
rosaPalabras mágicas de Luau. Siempre son las mismas. No se pueden usar como nombre.local function if then end return
celesteFunciones: máquinas que hacen algo. Siempre van con paréntesis ( ).print() Clone() atrapar()
amarilloTexto, entre comillas. El juego lo copia tal cual."¡Hola!" "Meta"
violetaNúmeros, y también sí / no (true = sí, false = no) y nil (= nada).24 0.9 true nil
naranjaLugares de Roblox que ya existen. Desde ahí empezás a buscar.workspace game script math
celeste claritoAlgo que está adentro de otra cosa (después de un punto)..Parent .Position .Meta
rojoSignos: guardar, sumar, comparar, pegar textos.= + == ..
verdeComentarios: notas para nosotros. El juego no las lee.-- esto es una nota
blancoNombres que inventamos nosotros (variables).vidas meta gusano

Un pedacito de mi juego, con colores

-- Partida: ¿cuántos puntos te doy?
local function calcularPuntos(segundos, piezas)
    local puntos = math.max(100, 5000 - 15 * segundos)
    return puntos * (1 + 0.1 * piezas)
end

print("Puntos: " .. calcularPuntos(120, 3))

Leelo por colores:

  • verde: una nota que explica qué hace.
  • rosa: local function = "acá armo una máquina". return = "devolvé esto". end = fin.
  • celeste: calcularPuntos, max y print son funciones.
  • violeta: los números de la cuenta.
  • amarillo: el texto que se muestra.
⚙️¿Qué es una función?
Las máquinas celestes del código.
🎯 Jueguito: ¿de qué color es "Escalon"? ¿Y 96?

"Escalon" tiene comillas: es texto, amarillo. 96 es un número, violeta.

🎯 Jueguito: en bloque:Destroy(), ¿qué color tiene Destroy? ¿Por qué?

Celeste, porque tiene paréntesis (): es una función. Hace algo: ¡rompe el bloque! 💥
